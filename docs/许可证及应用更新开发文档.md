# 客户端集成指南 / Client Integration Guide

本文档描述了如何将应用与 Keygate 许可证系统集成，涵盖购买、激活、验证、更新检测和防篡改等完整流程。

This document describes how to integrate your application with the Keygate licensing system, covering the complete workflow including purchase, activation, verification, update detection, and tamper protection.

---

## 基础配置 / Basic Configuration

### API 端点 / API Endpoints

```
Base URL: https://your-domain.com/api/v1
```

所有请求需要设置以下请求头 / All requests require the following headers:

```
Content-Type: application/json
User-Agent: YourApp/1.0.0
```

### 产品识别 / Product Identification

许可证 API 端点需要通过以下方式之一识别产品：

License API endpoints require product identification via one of:

1. **URL 路径参数** / Path parameter: `/api/v1/license/:product_slug/activate`
2. **请求头** / Header: `X-Product-ID: your-product-slug`
3. **查询参数** / Query parameter: `?product_id=your-product-slug`

```swift
func getMachineID() -> String {

        platformExpert,
        kIOPlatformSerialNumberKey as CFString,
        kCFAllocatorDefault,
        0

    IOObjectRelease(platformExpert)
    return serialNumberKey as? String ?? ""
}
```


### 验证频率建议 / Verification Frequency Recommendations

2. **定期验证**: 每 24 小时验证一次
   Periodic verification every 24 hours

3. **离线宽限期**: 允许 7-30 天的离线使用
   Offline grace period of 7-30 days

4. **缓存验证结果**: 验证成功后缓存结果，离线时使用缓存
   Cache verification result for offline use

### 实现示例 / Implementation Example

```swift
class LicenseValidator {
    private let offlineGraceDays = 7
    private let verificationInterval: TimeInterval = 86400 // 24 hours
    
    func shouldVerify() -> Bool {
        guard let lastCheck = UserDefaults.standard.object(forKey: "last_license_check") as? Date else {
            return true
        }
        return Date().timeIntervalSince(lastCheck) > verificationInterval
    }
    
    func verify() async throws -> Bool {
        if !NetworkMonitor.shared.isConnected {
            return verifyOffline()
        }
        
        let response = try await api.verifyLicense(
            key: savedLicenseKey,
            identifier: deviceID
        )
        
        if response.valid {
            UserDefaults.standard.set(Date(), forKey: "last_license_check")
            UserDefaults.standard.set(response, forKey: "cached_verification")
        }
        
        return response.valid
    }
    
    func verifyOffline() -> Bool {
        guard let lastCheck = UserDefaults.standard.object(forKey: "last_license_check") as? Date,
              let cached = UserDefaults.standard.object(forKey: "cached_verification") as? VerifyResponse else {
            return false
        }
        
        let daysSinceCheck = Date().timeIntervalSince(lastCheck) / 86400
        return daysSinceCheck <= Double(offlineGraceDays) && cached.valid
    }
}
```

## 4. 检测应用版本 / Check Application Version

**场景** / Scenario: 应用启动时检查是否有可用更新。
Check for available updates on app startup.

Keygate 支持三种主流更新框架的 feed 格式：
Keygate supports feed formats for three major update frameworks:

1. **Sparkle** (macOS): feed.xml
2. **Velopack** (Windows/macOS/Linux): feed.json
3. **Tauri** (跨平台): upgrade.json

### 更新访问控制 / Update Access Control

Keygate 支持两种更新访问模式：
Keygate supports two update access modes:

#### 公开 Feed / Public Feed

所有用户都可以访问更新，无需许可证验证。适用于免费应用或公开 Beta 测试。
All users can access updates without license verification. Suitable for free apps or public beta testing.

#### 许可证门控 Feed / License-Gated Feed

只有持有有效许可证的用户才能访问更新。访问方式：
Only users with valid licenses can access updates. Access methods:

1. **许可证密钥** / License key (推荐 / Recommended):
   ```
   GET /api/v1/releases/:product_slug/feed.xml?license_key=XXXX-XXXX
   ```

2. **签名令牌** / Signed token (激活后获得 / Obtained after activation):
   ```
   GET /api/v1/releases/:product_slug/feed.xml?license_token=eyJhbGc...
   ```

许可证门控会检查：
License gating checks:
- 许可证是否有效（未过期、未暂停）/ License is valid (not expired, not suspended)
- 对于永久许可证，检查更新维护期（`updates_until`）/ For perpetual licenses, checks maintenance period (`updates_until`)

### 版本比较 / Version Comparison

```swift
func isNewerVersion(_ remote: String, than local: String) -> Bool {
    let remoteComponents = remote.split(separator: ".").compactMap { Int($0) }
    let localComponents = local.split(separator: ".").compactMap { Int($0) }
    
    for i in 0..<max(remoteComponents.count, localComponents.count) {
        let r = i < remoteComponents.count ? remoteComponents[i] : 0
        let l = i < localComponents.count ? localComponents[i] : 0
        if r > l { return true }
        if r < l { return false }
    }
    return false
}
```

## 5. 校验应用完整性（防篡改）/ Verify Application Integrity (Anti-Tamper)

**场景** / Scenario: 防止应用被篡改或破解。
Prevent application tampering or cracking.

### 5.1 代码签名验证 / Code Signature Verification

**macOS**:
```swift
import Security

func verifyCodeSignature() -> Bool {
    let bundle = Bundle.main
    guard let bundlePath = bundle.bundlePath as CFString? else { return false }
    
    var staticCode: SecStaticCode?
    var status = SecStaticCodeCreateWithPath(
        bundlePath as CFURL,
        SecCSFlags(),
        &staticCode
    )
    
    guard status == errSecSuccess, let code = staticCode else {
        return false
    }
    
    // 验证签名有效性
    status = SecStaticCodeCheckValidity(
        code,
        SecCSFlags(rawValue: kSecCSCheckAllArchitectures),
        nil
    )
    
    return status == errSecSuccess
}

// 在应用启动时调用
if !verifyCodeSignature() {
    fatalError("Application signature verification failed")
}
```

**Windows**:
```csharp
using System.Security.Cryptography;
using System.Security.Cryptography.X509Certificates;

bool VerifyCodeSignature()
```

### 5.2 校验文件完整性 / File Integrity Check

对关键文件进行 SHA-256 校验：
Perform SHA-256 checksum on critical files:

```swift
import CryptoKit

func computeSHA256(filePath: String) -> String? {
    guard let data = try? Data(contentsOf: URL(fileURLWithPath: filePath)) else {
        return nil
    }
    let hash = SHA256.hash(data: data)
    return hash.compactMap { String(format: "%02x", $0) }.joined()
}

func verifyFileIntegrity() -> Bool {
    let criticalFiles = [
        "/path/to/main.exe": "expected_sha256_hash",
        "/path/to/core.dll": "expected_sha256_hash"
    ]
    
    for (file, expectedHash) in criticalFiles {
        guard let actualHash = computeSHA256(filePath: file),
              actualHash == expectedHash else {
            return false
        }
    }
    return true
}
```

```swift
import Darwin

func isDebuggerAttached() -> Bool {
    var info = kinfo_proc()
    var mib: [Int32] = [CTL_KERN, KERN_PROC, KERN_PROC_PID, getpid()]
```

### 5.4 许可证令牌验证 / License Token Verification

激活成功后，Keygate 返回一个签名的 JWT 令牌。应用应：
After activation, Keygate returns a signed JWT token. The app should:

1. **验证令牌签名** / Verify token signature
2. **检查令牌过期时间** / Check token expiration
3. **验证令牌中的产品 ID 和设备 ID** / Verify product ID and device ID in token

```swift
import JWTKit

func verifyLicenseToken(_ token: String) throws -> Bool {
    let publicKey = """
    -----BEGIN PUBLIC KEY-----
    YOUR_ED25519_PUBLIC_KEY
    -----END PUBLIC KEY-----
    """
    
    let signers = JWTSigners()
    try signers.use(.es256(key: .public(pem: publicKey)))
    
    let payload = try signers.verify(token, as: LicensePayload.self)
    
    // 验证设备 ID
    guard payload.identifier == currentDeviceID else {
        return false
    }
    
    // 验证过期时间
    guard payload.expiresAt > Date() else {
        return false
    }
    
    return true
}
```

### 5.5 最佳实践 / Best Practices

1. **混淆关键代码** / Obfuscate critical code: 使用代码混淆工具保护许可证验证逻辑
   Use code obfuscation tools to protect license verification logic

2. **多层验证** / Multi-layer verification: 在多个地方验证许可证，不要只在启动时验证一次
   Verify license at multiple points, not just once at startup

3. **不要硬编码密钥** / Don't hardcode keys: 许可证密钥和令牌应从安全存储读取，不要硬编码在代码中
   Read license keys and tokens from secure storage, never hardcode them

4. **定期服务器验证** / Periodic server validation: 不要完全依赖本地验证，定期与服务器同步
   Don't rely solely on local verification, periodically sync with the server

5. **优雅降级** / Graceful degradation: 当无法验证时（如网络故障），提供宽限期而不是立即锁定应用
   Provide grace period instead of immediate lockout when verification fails (e.g., network issues)

## 7. 检测许可证过期 / Detect License Expiration

### 7.1 本地检测 / Local Detection

在每次验证响应中，检查 `valid_until` 字段：
In each verification response, check the `valid_until` field:

```swift
struct VerifyResponse {
    let valid: Bool
    let validUntil: Date?
    let status: String
}

func checkExpiration(response: VerifyResponse) -> ExpirationStatus {
    guard let validUntil = response.validUntil else {
        return .perpetual // 永久许可证
    }
    
    let daysUntilExpiration = Calendar.current.dateComponents(
        [.day],
        from: Date(),
        to: validUntil
    ).day ?? 0
    
    if daysUntilExpiration < 0 {
        return .expired
    } else if daysUntilExpiration <= 7 {
        return .expiringSoon(days: daysUntilExpiration)
    } else {
        return .valid
    }
}

enum ExpirationStatus {
    case valid
    case expiringSoon(days: Int)
    case expired
    case perpetual
}
```

### 7.2 更新维护期检测（永久许可证）/ Maintenance Period Detection (Perpetual License)

永久许可证不会过期，但可能有更新维护期限制：
Perpetual licenses don't expire, but may have maintenance period restrictions:

```swift
struct LicenseInfo {
    let licenseType: String
    let validUntil: Date? // 许可证到期日
    let updatesUntil: Date? // 更新维护到期日
}

func checkMaintenancePeriod(info: LicenseInfo) -> MaintenanceStatus {
    // 只有永久许可证才有更新维护期的概念
    guard info.licenseType == "perpetual" else {
        return .notApplicable
    }
    
    guard let updatesUntil = info.updatesUntil else {
        return .lifetime // 终身更新
    }
    
    let daysUntilExpiration = Calendar.current.dateComponents(
        [.day],
        from: Date(),
        to: updatesUntil
    ).day ?? 0
    
    if daysUntilExpiration < 0 {
        return .ended
    } else if daysUntilExpiration <= 30 {
        return .endingSoon(days: daysUntilExpiration)
    } else {
        return .active
    }
}

enum MaintenanceStatus {
    case active
    case endingSoon(days: Int)
    case ended
    case lifetime
    case notApplicable
}
```

```swift
        set { KeychainWrapper.standard.set(newValue ?? "", forKey: "license_key") }

        return getMachineID()

    func fetchPlans() async throws -> [Plan] {
        let url = URL(string: "\(baseURL)/products/\(productSlug)/plans")!
        let (data, _) = try await URLSession.shared.data(from: url)
        let response = try JSONDecoder().decode(PlansResponse.self, from: data)
        return response.plans
    }
    
    // 2. 激活许可证
    func activate(licenseKey: String, label: String) async throws -> ActivateResponse {
        let url = URL(string: "\(baseURL)/license/activate")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue(productSlug, forHTTPHeaderField: "X-Product-ID")
        
        let body = [
            "license_key": licenseKey,
            "identifier": deviceID,
            "identifier_type": "device",
            "label": label
        ]
        request.httpBody = try JSONEncoder().encode(body)
        
        let (data, _) = try await URLSession.shared.data(for: request)
        let response = try JSONDecoder().decode(ActivateResponse.self, from: data)
        
        // 保存激活信息
        self.licenseKey = licenseKey
        KeychainWrapper.standard.set(response.token, forKey: "license_token")
        UserDefaults.standard.set(Date(), forKey: "last_license_check")
        
        return response
    }
    
    // 3. 验证许可证
    func verify() async throws -> VerifyResponse {
        guard let licenseKey = licenseKey else {
            throw LicenseError.notActivated
        }
        
        let url = URL(string: "\(baseURL)/license/verify")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue(productSlug, forHTTPHeaderField: "X-Product-ID")
        
        let body = [
            "license_key": licenseKey,
            "identifier": deviceID
        ]
        request.httpBody = try JSONEncoder().encode(body)
        
        let (data, _) = try await URLSession.shared.data(for: request)
        let response = try JSONDecoder().decode(VerifyResponse.self, from: data)
        
        if response.valid {
            UserDefaults.standard.set(Date(), forKey: "last_license_check")
            UserDefaults.standard.set(data, forKey: "cached_verification")
        }
        
        return response
    }
    
    // 4. 检查更新
    func checkForUpdates() async throws -> UpdateInfo? {
        // 使用 Sparkle 框架自动处理
        // 或自定义实现
        let updater = SPUUpdater(...)
        try await updater.checkForUpdates()
        return nil
    }
    
    // 5. 校验应用完整性
    func verifyIntegrity() -> Bool {
        return verifyCodeSignature() && verifyFileIntegrity()
    }
    
    // 6. 取消激活
    func deactivate() async throws {
        guard let licenseKey = licenseKey else {
            throw LicenseError.notActivated
        }
        
        let url = URL(string: "\(baseURL)/license/deactivate")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue(productSlug, forHTTPHeaderField: "X-Product-ID")
        
        let body = [
            "license_key": licenseKey,
            "identifier": deviceID
        ]
        request.httpBody = try JSONEncoder().encode(body)
        
        let (_, _) = try await URLSession.shared.data(for: request)
        
        // 清除本地数据
        self.licenseKey = nil
        KeychainWrapper.standard.removeObject(forKey: "license_token")
        UserDefaults.standard.removeObject(forKey: "last_license_check")
        UserDefaults.standard.removeObject(forKey: "cached_verification")
    }
    
    // 7. 检测过期状态
    func checkExpiration() async throws -> ExpirationStatus {
        let response = try await verify()
        
        guard let validUntil = response.validUntil else {
            return .perpetual
        }
        
        let daysUntilExpiration = Calendar.current.dateComponents(
            [.day],
            from: Date(),
            to: validUntil
        ).day ?? 0
        
        if daysUntilExpiration < 0 {
            return .expired
        } else if daysUntilExpiration <= 7 {
            return .expiringSoon(days: daysUntilExpiration)
        } else {
            return .valid
        }
    }
}
```

## 安全建议 / Security Recommendations

1. **使用 HTTPS**: 所有 API 请求必须通过 HTTPS
   Always use HTTPS for all API requests

2. **不要在日志中记录密钥**: 许可证密钥和令牌不应出现在日志或崩溃报告中
   Never log license keys or tokens in logs or crash reports

3. **安全存储**: 使用操作系统提供的安全存储机制（Keychain/Credential Manager）
   Use OS-provided secure storage (Keychain/Credential Manager)

4. **证书固定** (可选): 对于高安全性需求，实现证书固定防止中间人攻击
   Certificate pinning (optional): Implement for high-security needs to prevent MITM attacks

5. **混淆敏感代码**: 使用代码混淆保护许可证验证逻辑
   Obfuscate sensitive code: Protect license verification logic with code obfuscation

6. **定期验证**: 不要完全信任本地缓存，定期与服务器验证
   Regular verification: Don't fully trust local cache, verify with server periodically

7. **宽限期**: 提供合理的离线宽限期，避免误封正常用户
   Grace period: Provide reasonable offline grace period to avoid blocking legitimate users
