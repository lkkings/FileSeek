# Backend Requirements: FileSeek Desktop (基于UI交互全推断的需求文档)

## Context
FileSeek 是一款桌面多模态智能文件检索与资产管理系统。前端由 React + TypeScript 构建，基于完整的 UI 交互逻辑（包含顶栏检索、高级过滤、双层文件夹结构、时间戳秒级定位、文档页码行号高亮、入库处理队列、回收站管理以及 NAS 凭据配置），向后端发起数据交互与存储控制。

本文档**完全基于前端 `desktop/src` 的实际 UI 视图、组件交互及状态流转**推断整理，不依赖任何旧版 API 代码定义。

---

## Screens/Components

### 1. 全局顶部搜索栏与高级筛选抽屉 (Top SearchBar & Advanced Filter Drawer)
**Purpose**: 随时发起自然语言语义搜索、指定媒体类型，并结合文件名、文件体积及修改日期进行精确检索。

**Data I need to display**:
- **实时搜索状态指示**：当前检索状态（空闲、搜索中、检索失败）、检索结果统计数（例如：“找到 15 条结果”）。
- **高级筛选字段控制**：
  - 文件名模糊包含关键字。
  - 文件体积范围（最小 MB ~ 最大 MB）。
  - 修改时间范围（开始日期 ~ 结束日期）。
- **媒体分类 Tab 状态**：全部 (`all`)、文档 (`document`)、图片 (`image`)、视频 (`video`)。

**Actions**:
- **提交文本语义查询** → 触发向量语义匹配并刷新搜索视图。
- **展开/收起高级筛选抽屉** → 展开抽屉输入维度过滤项。
- **应用高级筛选条件** → 结合文本与筛选维度重新请求匹配数据。
- **重置筛选条件** → 清空高过滤项并还原检索结果。
- **切换媒体大类 Tab** → 实时按选中类别过滤当前搜索或重新发起定向查询。

**States to handle**:
- **Empty**: 未输入任何关键词与筛选条件时，保持原页面视图；搜索无匹配时显示空状态提示。
- **Loading**: 输入框右侧显示 Spinner 旋转图标，禁用 Tab 点击防止重复提交。
- **Error**: 服务不可用或超时时，顶部显示 Alert 报错信息。

### 2. 搜索结果列表与精准定位预览 (Search Results & Precision Preview)
**Purpose**: 统一展示综合相关度评分的检索匹配项，并支持一键精准定位至文档页/行及视频片段时间戳。

**Data I need to display**:
- **统一排序列表**：所有结果按相关性综合评分（百分比分值）从高到低混排。
- **单项文件基础元数据**：文件名、高亮匹配子串、文件类型 Badge、完整存储路径、评分、在线/挂载状态（Accessible）。
- **文档专属匹配信息**：
  - 命中的文本上下文摘要（Matched Snippet）。
  - 命中的页码（`P.X`）与命中的行号（`L.Y`）。
- **图片专属匹配信息**：
  - 图片缩略图预览。
  - 可访问性提示（如：“由于外部挂载点断开，图片暂不可访问”）。
- **视频专属匹配信息**：
  - 命中的视频片段列表（Segments），每个片段包含：起始时间（`start_time`）、结束时间（`end_time`）、片段相似度得分、AI 生成的片段剧情总结（Summary）、片段缩略图。
- **分页/加载更多（Load More）**：标识文档、图片、视频各自是否还有下一页（`has_more_documents` / `has_more_images` / `has_more_videos`）。

**Actions**:
- **点击文档搜索结果** → 唤起全屏文件预览模态框（`FilePreviewModal`），自动跳转至目标页码 `P.X`，并用黄色卡片与 Badge 标出第 `L.Y` 行匹配文本。
- **点击视频片段时间戳按钮（▶ 01:23 - 02:00）** → 打开文件预览模态框，视频播放器自动 Seek 定位至 `01:23` 秒并自动开始播放，右侧同步加载全视频的时间轴片段列表供快速跳转。
- **点击图片搜索结果** → 打开文件预览模态框，提供高清渲染、旋转（90°/180°/270°）、放大/缩小及重置画布功能。
- **在文件管理器中定位（📁 按钮）** → 调用系统文件管理器选中并高亮该文件。
- **用系统默认应用打开（↗ 按钮）** → 唤起操作系统关联的默认软件打开该文件。
- **点击“加载更多”** → 追加加载下一页搜索结果。

**States to handle**:
- **Inaccessible (离线/断开)**: 当文件所在 NAS 或移动硬盘未挂载时，列表项呈半透明灰色，提示挂载点断开，禁用预览与系统打开按钮。
- **Doc Page Highlight**: 打开 PDF/Word 预览时，顶部显示 `📍 已定位至第 X 页 / 第 Y 行` 标识。

### 3. 文件库与双层文件夹管理 (File Library & Folder Management)
**Purpose**: 实现类似 macOS Finder 的文件夹分类组织、子文件夹属性编辑、文件导入与批量删改。

**Data I need to display**:
- **根层级视图（Root Level）**：
  - 自定义文件夹卡片列表（如：毕业旅行、工作文档、个人相册、视频剪辑、代码仓库、学习资料）。
  - 文件夹图标样式（`travel` / `work` / `photos` / `videos` / `default`）、文件夹描述说明、包含内容简介、更新时间。
  - 文件夹分页导航（分页显示）。
- **子文件夹视图（Sub-folder View）**：
  - 面包屑导航（`< 返回文件库`）。
  - 当前文件夹名称及描述，修改描述与图标的编辑按钮。
  - 文件夹内部的文件全量列表/网格：显示缩略图、文件名、扩展名颜色图标、体积大小、修改时间、本地/NAS/云盘路径标识。
  - 多选勾选框（Point Select & Batch Delete）。
- **回收站视图（Recycle Bin）**：
  - 待清空/可还原的已删除文件列表（包含删除前文件名、体积、原路径）。

**Actions**:
- **新建文件夹** → 输入文件夹名称、选择定制图标、填写描述信息。
- **编辑文件夹属性** → 修改已有文件夹的名称、图标及描述（若改名，内部文件的父级目录关联自动同步更新）。
- **删除文件夹** → 校验文件夹是否为空，若存在文件则阻止删除并弹窗提示；确认后删除。
- **在子文件夹内添加文件** → 选择来源（本地绝对路径、NAS `nas://` 路径、云盘 `cloud://` 路径），支持单文件添加或勾选“批量导入整个文件夹”。
- **文件多选与批量删除** → 勾选多个文件后，顶部出现批量删除按钮，确认后移入回收站。
- **切换显示模式** → 列表模式（List）与网格大图模式（Grid）自由切换。
- **表格排序** → 按文件名（中文拼音）、文件体积（KB/MB/GB 自动换算）、修改时间进行升序/降序排序。
- **回收站操作** → 单项还原（Restore）、单项彻底删除（Delete Permanently）、一键清空回收站（Clean Recycle Bin）。

### 4. 批量导入与索引任务队列 (Ingest & Task Queue)
**Purpose**: 批量拖拽文件/文件夹提交入库，并监控后台多阶段向量化处理进度。

**Data I need to display**:
- **导入准备区**：支持拖拽文件/文件夹，手动浏览选择本地/相机/云盘来源，自动识别并过滤不支持的文件类型（如 `.raw`），显示待导入队列列表与文件体积。
- **任务队列看板（Task Queue）**：
  - 状态分类 Tab：全部 (`all`)、处理中 (`processing`)、已完成 (`completed`)、失败 (`failed`)。
  - 任务列表项：任务 ID、源文件路径、当前状态 Badge（queued / processing / completed / failed）、创建时间。
  - 实时处理进度条（0-100%）、当前处理阶段（`moved` 文件移入 → `extracted` 内容提取 → `encoded` 特征向量化 → `indexed` 索引入库）。
  - 失败任务的错误诊断描述（如：“无法解码视频容器: 帧突变严重”）。
- **侧边栏通知 Badge**：侧边栏“处理队列”导航项上实时显示正在处理中（`processing`）的任务数量。

**Actions**:
- **提交导入任务** → 提交待导入文件路径数组，后端返回接受数量与跳过数量，并生成后台任务。
- **重试失败任务** → 针对状态为 `failed` 的任务发起重试，保留上一次已完成的阶段断点。
- **任务状态轮询与事件更新** → 前端定期或通过事件更新任务队列与侧边栏 Badge 计数。

### 5. 系统设置与 NAS 存储配置 (System Settings)
**Purpose**: 管理存储根目录路径与 NAS 网络共享挂载凭据。

**Data I need to display**:
- **通用设置**：
  - 库根目录路径 (`lib_root`) 输入框与选择按钮。
  - 界面语言下拉选择（中文 `zh` / 英文 `en`）。
- **外观设置**：
  - 主题切换按钮（深色 `dark` / 浅色 `light`）。
- **NAS 挂载配置**：
  - NAS 连接状态 Badge：已连接（Connected） / 已断开（Disconnected）。
  - 协议选择：SMB / CIFS（推荐）、NFS、AFP。
  - 主机 IP / 地址、共享路径、用户名、密码。
  - 连通性测试结果反馈框（成功提示或超时/错误原因）。
- **关于软件**：
  - 版本号与说明。

**Actions**:
- **更改库根目录** → 输入新路径，后端校验写权限，若无写入权限提示“目录不可写。请选择具有写权限的本地文件夹。”
- **测试 NAS 连接** → 提交凭据与网络配置，发起即时连通性测试。

## Uncertainties
- [ ] 当用户在 UI 中对文件夹重命名时，存储在 NAS 或本地磁盘上的真实物理目录是否同步重命名？
- [ ] 视频在播放预览时，非原生网页视频格式（如 `.mkv`, `.avi`, `.flv`, `.wmv`, `.ts`）是否由后端转码服务（如 FFmpeg）实时转码为 MP4 流提供给前端？
- [ ] 批量删除文件移入回收站后，其向量索引是立即彻底从向量库中删除，还是仅做软删除标记以便“还原”？

## Questions for Backend
- 后端是否可以支持 Server-Sent Events (SSE) 接口 `/api/v1/tasks/stream` 以代替前端 5 秒一次的 `/tasks` 轮询？
- 对于大视频流播放，视频流响应头部是否完整支持 `Accept-Ranges: bytes` 和 `206 Partial Content`，以保证拖拽 Seek 时的极速响应？
- 文档的匹配行号 (`line_number`) 与页码 (`page_number`) 提取，在 Word (`.docx`) 及 Markdown/TXT 文档中是如何定义的？
