## Why

文件夹详情页当前的筛选入口、标签管理、排序布局、表格列和分页实现不一致，无法在侧边栏折叠/展开和小屏场景下稳定适配。用户需要更清晰的搜索控制、可维护的标签选择，以及与现有文件详情抽屉、分页和预览交互一致的列表体验。

## What Changes

- 将“高级筛选”入口改为搜索图标按钮，点击后打开文件夹内搜索栏，再次点击关闭；激活态使用填充图标。
- 将标签筛选与文件类型筛选同行展示，右侧提供“添加标签”图标按钮，点击后弹出后端标签列表供用户选择。
- 将排序组件放在“共 * 个文件”同一行右侧，保持水平排列。
- 优化表格视图与列表视图在侧边栏折叠/展开后的响应式适配；列表列调整为“预览、标签、文件名、大小”，移除“路径”“操作”。
- 复用现有分页组件，避免各视图重复实现分页。
- 点击文件项打开右侧文件详情抽屉，双击文件项直接打开预览。

## Capabilities

### New Capabilities

- `library/folder-details-view`: 规范文件夹详情页的搜索入口、标签选择、布局适配、列表列、分页和文件项交互。

### Modified Capabilities

- 无。

## Impact

- 影响 `FolderDetailsView`、标签选择弹层、分页组件复用、表格/列表列定义、文件详情抽屉与预览触发逻辑。
- 需要复用现有后端标签列表接口；若当前 API 尚未提供标签列表，则需在 API 层补齐调用。
- 不引入新的第三方依赖。
